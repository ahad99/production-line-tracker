## ✨ Features

* **Production Dashboard** — Overview of factory production and operational performance.
* **Production Monitoring** — Visual representation of production line activities.
* **Workflow Management** — Interface concepts for managing factory operations.
* **Modern UI** — Clean, intuitive, and responsive design.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the interactive demo.

No additional installation is required.

This project demonstrates AI-assisted product development, rapid prototyping, and the transformation of business requirements into a visual ERP interface.
